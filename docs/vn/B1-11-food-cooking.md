# Đồ ăn & Nấu ăn

## Từ vựng Nấu ăn thiết yếu

Khi nấu ăn hoặc nói về đồ ăn, bạn cần các từ cho nguyên liệu, cách nấu và dụng cụ nhà bếp.

> **Mẫu câu**: `First, you need to [verb] the [ingredient]. Then, [action].`

## Các nguyên liệu phổ biến

|                | Tiếng Anh       | Tiếng Việt |
| -------------- | --------------- | ---------- |
| vegetables     | rau củ          |
| fruits         | trái cây        |
| meat           | thịt            |
| poultry        | gia cầm         |
| seafood        | hải sản         |
| dairy products | sản phẩm từ sữa |
| grains         | ngũ cốc         |
| spices         | gia vị          |
| herbs          | rau thơm        |

## Các phương pháp nấu

|           | Tiếng Anh    | Tiếng Việt |
| --------- | ------------ | ---------- |
| to boil   | đun sôi      |
| to fry    | chiên        |
| to bake   | nướng (lò)   |
| to grill  | nướng (than) |
| to steam  | hấp          |
| to roast  | rang         |
| to stir   | khuấy        |
| to simmer | đun nhỏ lửa  |

## Các hành động khi nấu

|                   | Tiếng Anh     | Tiếng Việt |
| ----------------- | ------------- | ---------- |
| to chop           | thái, băm     |
| to slice          | thái lát mỏng |
| to peel           | gọt vỏ        |
| to grate          | nạo           |
| to mix / to blend | trộn / xay    |
| to pour           | đổ            |
| to stir-fry       | xào           |
| to knead          | nhào bột      |

## Các cụm từ nấu ăn hữu ích

> "I'm going to cook pasta for dinner tonight." — Tối nay tôi sẽ nấu mì Ý.
> "First, you need to chop the vegetables." — Đầu tiên, bạn cần thái rau củ.
> "Add the ingredients one at a time." — Cho nguyên liệu vào từng thứ một.
> "Let it simmer for 20 minutes." — Đun nhỏ lửa 20 phút.
> "Don't forget to season with salt and pepper." — Đừng quên nêm muối và tiêu.

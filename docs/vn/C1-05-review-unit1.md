# Ôn tập Unit 1

## Những gì chúng ta đã học

Trong Unit 1, bạn đã xây dựng các kỹ năng giao tiếp cấp điều hành:

1. **Cuộc họp điều hành** — Dẫn dắt thảo luận cấp C
2. **Thuyết trình hội đồng** — Trình bày trước các giám đốc
3. **Đọc tài liệu chiến lược** — Phân tích báo cáo thường niên
4. **Quản lý bên liên quan** — Điều hướng ảnh hưởng

## Ôn tập nhanh

### Cuộc họp điều hành

| Cụm từ                 | Sử dụng                   |
| ---------------------- | ------------------------- |
| take this offline      | Chuyển thảo luận sang bên |
| circle back            | Quay lại chủ đề           |
| table that for now     | Hoãn thảo luận            |
| run it up the flagpole | Thử một ý tưởng           |

### Thuyết trình hội đồng

| Phần              | Mục đích             |
| ----------------- | -------------------- |
| Tóm tắt điều hành | Quyết định chính cần |
| Số liệu chính     | Bảng hiệu suất       |
| Rủi ro            | Kế hoạch giảm thiểu  |
| Khuyến nghị       | Yêu cầu rõ ràng      |

### Từ vựng chiến lược

| Thuật ngữ         | Ý nghĩa                  |
| ----------------- | ------------------------ |
| headwinds         | thách thức               |
| tailwinds         | điều kiện thuận lợi      |
| pivot             | chuyển hướng chiến lược  |
| value proposition | giá trị độc đáo cung cấp |

### Quản lý bên liên quan

| Thuật ngữ          | Sử dụng                        |
| ------------------ | ------------------------------ |
| buy-in             | Đồng thuận và ủng hộ           |
| bring on board     | Đảm bảo sự ủng hộ              |
| align expectations | Đảm bảo hiểu biết chung        |
| champion           | Người ủng hộ tích cực          |
| gatekeeper         | Người kiểm soát quyền truy cập |

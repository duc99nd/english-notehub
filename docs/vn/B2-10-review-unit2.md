# Ôn tập Unit 2

## Những gì chúng ta đã học

Trong Unit 2, bạn đã xây dựng trên nền tảng B1 với 5 kỹ năng nâng cao:

1. **Điều phối cuộc họp** — dẫn dắt cuộc họp tự tin
2. **Ngữ pháp thuyết phục** — dùng ngữ pháp để thuyết phục
3. **Đọc bài báo kinh doanh** — phân tích báo cáo thị trường
4. **Viết đề xuất** — cấu trúc đề xuất thuyết phục
5. **Kể chuyện bằng dữ liệu** — trình bày insights hiệu quả

Cộng thêm: **Câu điều kiện hỗn hợp nâng cao** cho các tình huống giả định.

## Ôn tập nhanh

### Cụm từ điều phối họp

| Cụm từ          | Sử dụng           |
| --------------- | ----------------- |
| kick off        | Bắt đầu cuộc họp  |
| park that topic | Hoãn lại sau      |
| tiebreaker      | Phá vỡ bế tắc     |
| draw to a close | Kết thúc cuộc họp |

### Mẫu ngữ pháp thuyết phục

- **Câu chẻ**: What matters is the outcome.
- **Đảo ngữ**: Not only does it reduce costs, but it also improves quality.
- **So sánh kép**: The more we test, the better the result becomes.

### Câu điều kiện

| Loại    | Cấu trúc                       | Sử dụng                 |
| ------- | ------------------------------ | ----------------------- |
| Loại 3  | If + had + pp, would have + pp | Giả định quá khứ        |
| Hỗn hợp | quá khứ + hiện tại             | Kết nối khung thời gian |

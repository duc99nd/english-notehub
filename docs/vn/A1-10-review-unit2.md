# Ôn tập Unit 2

## Bạn đã học được gì?

Trong Unit 2, bạn đã học năm bài quan trọng:

1. **Thời gian & Địa điểm** — Thời gian trong ngày, các ngày trong tuần, địa điểm phổ biến
2. **Thức ăn & Đồ uống** — Từ vựng về thức ăn và cách gọi món
3. **Thời tiết** — Mô tả thời tiết và các mùa
4. **Sở thích** — Nói về những gì bạn thích làm

## Ôn tập nhanh

### Thời gian & Địa điểm

| Tiếng Anh | Tiếng Việt |
| --------- | ---------- |
| morning   | buổi sáng  |
| afternoon | buổi chiều |
| evening   | buổi tối   |
| home      | nhà        |
| school    | trường học |

### Thức ăn

| Tiếng Anh | Tiếng Việt |
| --------- | ---------- |
| rice      | cơm        |
| chicken   | thịt gà    |
| water     | nước       |
| coffee    | cà phê     |

### Thời tiết

| Tiếng Anh | Tiếng Việt |
| --------- | ---------- |
| sunny     | nắng       |
| rainy     | mưa        |
| hot       | nóng       |
| cold      | lạnh       |

### Sở thích

| Tiếng Anh       | Tiếng Việt    |
| --------------- | ------------- |
| read books      | đọc sách      |
| watch movies    | xem phim      |
| listen to music | nghe nhạc     |
| play sports     | chơi thể thao |

## Các mẫu câu quan trọng

> **Giới từ**: `at home`, `in the morning`, `on Monday`
>
> **Gọi món**: `I would like some rice, please.`
>
> **Thời tiết**: `It is sunny today.`
>
> **Sở thích**: `I like to read books.`

## Bài tập thực hành

### Bài tập 1: Điền vào chỗ trống

1. `I eat breakfast in the ___. (buổi sáng)`
2. `I would like some ___, please. (nước)`
3. `It is ___ today. It is raining. (mưa)`

### Bài tập 2: Nối các cặp

- morning - buổi sáng
- chicken - thịt gà
- hot - nóng
- read - đọc

## Bài học tiếp theo

Ở bài **A1-11-shopping-money**, bạn sẽ học từ vựng về mua sắm và tiền bạc.

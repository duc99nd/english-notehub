# Công việc & Thói quen hàng ngày

## Từ vựng công việc thiết yếu

Khi nói về công việc của bạn, bạn cần các từ cho các khía cạnh khác nhau của cuộc sống làm việc.

> **Mẫu câu**: `I work as a [profession]. I usually start at [time].`

## Nghề nghiệp

|                   | Tiếng Anh            | Tiếng Việt |
| ----------------- | -------------------- | ---------- |
| manager           | quản lý              |
| employee          | nhân viên            |
| colleague         | đồng nghiệp          |
| boss / supervisor | sếp / người giám sát |
| freelancer        | người làm tự do      |
| intern            | thực tập sinh        |
| consultant        | chuyên gia tư vấn    |

## Các nơi trong công ty

|              | Tiếng Anh           | Tiếng Việt |
| ------------ | ------------------- | ---------- |
| office       | văn phòng           |
| meeting room | phòng họp           |
| cubicle      | góc làm việc        |
| reception    | quầy lễ tân         |
| break room   | phòng nghỉ giải lao |
| desk         | bàn làm việc        |

## Các hoạt động công việc

|                        | Tiếng Anh         | Tiếng Việt |
| ---------------------- | ----------------- | ---------- |
| to attend a meeting    | tham dự cuộc họp  |
| to meet a deadline     | đáp ứng thời hạn  |
| to review documents    | xem lại tài liệu  |
| to give a presentation | thuyết trình      |
| to handle clients      | xử lý khách hàng  |
| to collaborate         | cộng tác          |
| to delegate            | ủy thác công việc |

## Các cụm từ công việc hữu ích

> "I usually start work at 9 AM." — Tôi thường bắt đầu làm việc lúc 9 giờ sáng.
> "I have a meeting with my manager this afternoon." — Chiều nay tôi có cuộc họp với quản lý.
> "I need to finish this report by Friday." — Tôi cần hoàn thành báo cáo này trước thứ Sáu.
> "Could you help me with this task?" — Bạn có thể giúp tôi với công việc này không?
> "I'll get back to you on that." — Tôi sẽ phản hồi bạn về việc đó.

## Lịch làm việc

- `full-time` — toàn thời gian
- `part-time` — bán thời gian
- `shift work` — làm việc theo ca
- `overtime` — tăng ca
- `remote work` — làm việc từ xa
- `hybrid` — kết hợp (văn phòng + từ xa)

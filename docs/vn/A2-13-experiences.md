# Kinh nghiệm

## Hiện tại hoàn thành cho kinh nghiệm cuộc sống

Dùng thì hiện tại hoàn thành để nói về những điều bạn đã làm trong đời. Chúng ta thường không nói chính xác khi nào.

> **Pattern**: `Chủ ngữ + have/has + quá khứ phân từ (V3)`

| Chủ ngữ          | Trợ động từ |
| ---------------- | ----------- |
| I, you, we, they | have        |
| He, she, it      | has         |

## Các cụm từ chỉ thời gian phổ biến

| Cụm từ                                        | Ví dụ                         |
| --------------------------------------------- | ----------------------------- |
| ever (đã từng)                                | "Bạn đã từng thử sushi chưa?" |
| never (chưa bao giờ)                          | "Tôi chưa bao giờ ăn ốc sên." |
| already (rồi)                                 | "Tôi đã xong rồi."            |
| yet (chưa)                                    | "Tôi chưa xong."              |
| once / twice / three times (một/ hai/ ba lần) | "Tôi đã đến hai lần."         |
| for + thời gian                               | "Tôi đã sống ở đây 5 năm."    |
| since + thời gian                             | "Tôi đã làm ở đây từ 2020."   |

## Ví dụ

| Tiếng Anh                    | Tiếng Việt                         |
| ---------------------------- | ---------------------------------- |
| I have visited Japan.        | Tôi đã từng đến Nhật Bản.          |
| She has tried sushi once.    | Cô ấy đã thử sushi một lần.        |
| We have never seen snow.     | Chúng tôi chưa bao giờ thấy tuyết. |
| Have you ever been to Paris? | Bạn đã từng đến Paris chưa?        |

## Quá khứ phân từ có quy tắc (V3)

| Động từ (V1)      | Quá khứ phân từ (V3) |
| ----------------- | -------------------- |
| visit (đến thăm)  | visited              |
| try (thử)         | tried                |
| finish (kết thúc) | finished             |
| live (sống)       | lived                |
| work (làm việc)   | worked               |
| play (chơi)       | played               |

## Quá khứ phân từ bất quy tắc

| Động từ (V1) | Quá khứ phân từ (V3) |
| ------------ | -------------------- |
| be (là)      | been                 |
| do (làm)     | done                 |
| eat (ăn)     | eaten                |
| see (thấy)   | seen                 |
| go (đi)      | gone                 |
| have (có)    | had                  |

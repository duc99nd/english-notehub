# Câu điều kiện hỗn hợp nâng cao

## Câu điều kiện loại 3 — giả định quá khứ

Câu điều kiện loại 3 nói về các sự kiện tưởng tượng trong quá khứ và kết quả tưởng tượng của chúng.

> **Pattern**: `If + quá khứ hoàn thành, would have + quá khứ phân từ`

| Tiếng Anh                                                 | Tiếng Việt                                   |
| --------------------------------------------------------- | -------------------------------------------- |
| If I had studied harder, I would have passed the exam.    | Nếu tôi học chăm hơn, tôi đã đậu kỳ thi.     |
| If she had left earlier, she would have caught the train. | Nếu cô ấy đi sớm hơn, cô ấy đã kịp tàu.      |
| Had I known about the meeting, I would have attended.     | Giá mà tôi biết về cuộc họp, tôi đã tham dự. |

## Câu điều kiện hỗn hợp

Câu điều kiện hỗn hợp kết nối nguyên nhân quá khứ với kết quả hiện tại, hoặc ngược lại.

> **Pattern A** (quá khứ → hiện tại): `If + quá khứ hoàn thành, would + động từ nguyên mẫu`
> **Pattern B** (hiện tại → quá khứ): `If + quá khứ đơn, would have + quá khứ phân từ`

| Pattern            | Example                                                         |
| ------------------ | --------------------------------------------------------------- |
| Quá khứ → Hiện tại | If I had studied medicine, I would be a doctor now.             |
| Hiện tại → Quá khứ | If she were more experienced, she would have handled it better. |

## Dấu hiệu thời gian phổ biến

- Yesterday / last week / in 2020 → giả định quá khứ
- Now / today / currently → kết quả hiện tại
- Always / every time → sự thật tổng quát

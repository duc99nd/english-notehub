# Du lịch & Phương tiện đi lại

## Từ vựng du lịch thiết yếu

Khi bạn đi du lịch, bạn cần biết các từ cho các loại phương tiện và hoạt động du lịch khác nhau.

> **Mẫu câu**: `I'm going to [destination] by [transport].`

## Các loại phương tiện

|                | Tiếng Anh     | Tiếng Việt |
| -------------- | ------------- | ---------- |
| flight         | chuyến bay    |
| train          | tàu hỏa       |
| bus            | xe buýt       |
| taxi / cab     | taxi          |
| car            | ô tô          |
| bicycle / bike | xe đạp        |
| ferry          | phà           |
| cruise         | du thuyền     |
| subway / metro | tàu điện ngầm |

## Các hoạt động du lịch

|                      | Tiếng Anh            | Tiếng Việt |
| -------------------- | -------------------- | ---------- |
| to book / to reserve | đặt (vé, phòng)      |
| to check in          | làm thủ tục check-in |
| to board             | lên máy bay/tàu      |
| to take off          | cất cánh             |
| to land              | hạ cánh              |
| to depart            | khởi hành            |
| to arrive            | đến nơi              |
| to delay             | bị trễ               |
| to cancel            | bị hủy               |

## Các cụm từ hữu ích khi đi du lịch

> "I'm planning a trip to [city]." — Tôi đang lên kế hoạch đi [thành phố].
> "I need to renew my passport." — Tôi cần gia hạn hộ chiếu.
> "Can you tell me how to get to the train station?" — Bạn có thể cho tôi biết làm sao đến nhà ga được không?
> "What time does the next bus depart?" — Chuyến xe buýt tiếp theo khởi hành lúc mấy giờ?
> "Is there a direct flight?" — Có chuyến bay thẳng không?
> "I'd like to book a window seat." — Tôi muốn đặt ghế cạnh cửa sổ.

## Ở sân bay / Nhà ga

- `check-in desk` — quầy làm thủ tục
- `departure lounge` — phòng chờ khởi hành
- `boarding pass` — thẻ lên máy bay
- `luggage / baggage` — hành lý
- `to miss a flight` — lỡ chuyến bay
- `to catch a train` — kịp tàu

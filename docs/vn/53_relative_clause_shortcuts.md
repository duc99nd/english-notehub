# Mẹo Rút Gọn Mệnh Đề Quan Hệ (Daily English)

Mệnh đề quan hệ được dùng để bổ sung chi tiết cho một danh từ (ví dụ: một con bug, một thư viện, hay một lập trình viên) mà không cần phải ngắt câu để viết câu mới. Việc sử dụng **rút gọn** mệnh đề quan hệ (reductions) là mẹo dễ nhất để bạn nói tiếng Anh ngắn gọn, tự nhiên như người bản xứ.

---

## 1. Các Đại từ Quan hệ Cốt lõi trong IT

Trước khi học mẹo rút gọn, hãy nhớ lại 5 đại từ quan hệ cơ bản sau:

- **that / which** (dùng cho công cụ, thư viện, tính năng): _"We fixed the bug **that** crashed the system."_ _(Chúng tôi đã sửa con bug làm sập hệ thống)._
- **who** (dùng cho đồng nghiệp, user, khách hàng): _"The engineer **who** designed this is on leave."_ _(Kỹ sư thiết kế cái này đang nghỉ phép)._
- **where** (dùng cho trang màn hình, vị trí, database): _"This is the screen **where** users change passwords."_ _(Đây là màn hình nơi user đổi mật khẩu)._
- **when** (dùng cho sự kiện, thời điểm, đợt release): _"That was the time **when** our traffic spiked."_ _(Đó là thời điểm lượng traffic của chúng ta tăng vọt)._

---

## 2. Mẹo 1: Rút gọn Chủ động (Dùng đuôi V-ing)

Nếu động từ trong mệnh đề quan hệ ở thể **chủ động** (danh từ đứng trước tự thực hiện hành động đó), bạn có thể bỏ đại từ quan hệ (_who/which/that_) và chuyển động từ chính về dạng thêm đuôi **-ing**.

- **Công thức:** `Danh từ + who/which/that + Động từ` ➔ `Danh từ + V-ing`

### 💡 10 Ví dụ thực tế:

1.  _Đầy đủ:_ "We found a bug **that blocks** the checkout page."
    ➔ **Rút gọn: "We found a bug blocking the checkout page."** _(Chúng tôi tìm thấy một con bug chặn trang checkout)._
2.  _Đầy đủ:_ "We need a tool **that generates** clean PDF reports."
    ➔ **Rút gọn: "We need a tool generating clean PDF reports."** _(Chúng tôi cần một công cụ tạo ra báo cáo PDF sạch đẹp)._
3.  _Đầy đủ:_ "The developer **who works** on this feature is out today."
    ➔ **Rút gọn: "The developer working on this feature is out today."** _(Developer làm tính năng này hôm nay nghỉ)._
4.  _Đầy đủ:_ "The script **that updates** user accounts is failing."
    ➔ **Rút gọn: "The script updating user accounts is failing."** _(Script cập nhật tài khoản người dùng đang bị lỗi)._
5.  _Đầy đủ:_ "We noticed a background service **that consumes** 90% CPU."
    ➔ **Rút gọn: "We noticed a background service consuming 90% CPU."** _(Chúng tôi phát hiện một dịch vụ ngầm ngốn tới 90% CPU)._
6.  _Đầy đủ:_ "Any query **that bypasses** the cache will slow down the page."
    ➔ **Rút gọn: "Any query bypassing the cache will slow down the page."** _(Bất kỳ câu query nào bỏ qua cache sẽ làm chậm trang)._
7.  _Đầy đủ:_ "We have multiple users **who complain** about the new payment layout."
    ➔ **Rút gọn: "We have multiple users complaining about the new payment layout."** _(Chúng tôi có nhiều user phàn nàn về layout thanh toán mới)._
8.  _Đầy đủ:_ "Is there an index **that speeds** up this join query?"
    ➔ **Rút gọn: "Is there an index speeding up this join query?"** _(Có index nào giúp tăng tốc câu query join này không?)_
9.  _Đầy đủ:_ "I am looking for a package **that supports** WebSocket connections."
    ➔ **Rút gọn: "I am looking for a package supporting WebSocket connections."** _(Tôi đang tìm một package hỗ trợ kết nối WebSocket)._
10. _Đầy đủ:_ "The server **that hosts** the staging database needs a reboot."
    ➔ **Rút gọn: "The server hosting the staging database needs a reboot."** _(Server host database staging cần được restart)._

## 3. Mẹo 2: Rút gọn Bị động (Dùng V3/ed)

Nếu động từ trong mệnh đề quan hệ ở thể **bị động** (danh từ đứng trước bị/được tác động, câu thường có cấu trúc `be + V3/ed`), bạn có thể bỏ cả đại từ quan hệ (_who/which/that_) lẫn động từ `be`, chỉ giữ lại động từ ở cột 3 hoặc đuôi **-ed**.

- **Công thức:** `Danh từ + who/which/that + is/are/was/were + V3/ed` ➔ `Danh từ + V3/ed`

### 💡 10 Ví dụ thực tế:

1.  _Đầy đủ:_ "This is the library **which was selected** by our team."
    ➔ **Rút gọn: "This is the library selected by our team."** _(Đây là thư viện được chọn bởi team chúng tôi)._
2.  _Đầy đủ:_ "The changes **that are deployed** yesterday are working fine."
    ➔ **Rút gọn: "The changes deployed yesterday are working fine."** _(Các thay đổi được deploy hôm qua đang chạy tốt)._
3.  _Đầy đủ:_ "Please review the code **that was written** by Huy."
    ➔ **Rút gọn: "Please review the code written by Huy."** _(Vui lòng review code được viết bởi Huy)._
4.  _Đầy đủ:_ "The features **that were requested** by the client are completed."
    ➔ **Rút gọn: "The features requested by the client are completed."** _(Các tính năng khách hàng yêu cầu đã được hoàn thành)._
5.  _Đầy đủ:_ "All logs **which are stored** in the folder are encrypted."
    ➔ **Rút gọn: "All logs stored in the folder are encrypted."** _(Tất cả log lưu trong thư mục đều được mã hóa)._
6.  _Đầy đủ:_ "The API keys **that are used** for authentication have expired."
    ➔ **Rút gọn: "The API keys used for authentication have expired."** _(Các API key dùng để xác thực đã hết hạn)._
7.  _Đầy đủ:_ "The database tables **which were created** last week need schema updates."
    ➔ **Rút gọn: "The database tables created last week need schema updates."** _(Các bảng database tạo tuần trước cần cập nhật schema)._
8.  _Đầy đủ:_ "This is the configuration **that is recommended** by the DevOps team."
    ➔ **Rút gọn: "This is the configuration recommended by the DevOps team."** _(Đây là cấu hình được khuyến nghị bởi team DevOps)._
9.  _Đầy đủ:_ "Only files **that are committed** to the main branch are deployed."
    ➔ **Rút gọn: "Only files committed to the main branch are deployed."** _(Chỉ những file được commit lên branch main mới được deploy)._
10. _Đầy đủ:_ "The server certificates **which were renewed** today are working."
    ➔ **Rút gọn: "The server certificates renewed today are working."** _(Các chứng chỉ server được gia hạn hôm nay đang hoạt động tốt)._

## 4. Mẹo 3: Liên kết câu bằng ", which" (Mệnh đề quan hệ nối tiếp)

Hãy dùng cụm `, which` (luôn có dấu phẩy đứng trước) ở cuối câu để bình luận hoặc chỉ ra hệ quả cho **toàn bộ sự việc bạn vừa nói ở vế trước**. Đây là cách nối ý cực kỳ chuyên nghiệp trong các buổi họp.

### 💡 10 Ví dụ thực tế:

1.  **"The server went offline at midnight, which caused the database connection to fail."** _(Server bị sập lúc nửa đêm, điều này làm cho kết nối database bị lỗi)._
2.  **"The client decided to change the designs, which means we have to rewrite the CSS."** _(Khách hàng quyết định đổi thiết kế, điều đó đồng nghĩa với việc chúng ta phải viết lại CSS)._
3.  **"We forgot to run the migrations on staging, which led to a schema mismatch error."** _(Chúng tôi quên chạy migration trên staging, dẫn đến lỗi lệch schema)._
4.  **"The API token expired early, which blocked the automated test suite."** _(Token API hết hạn sớm, làm chặn đứng bộ test tự động)._
5.  **"Huy refactored the query logic, which improved the response speed by 40%."** _(Huy đã refactor logic truy vấn, điều này cải thiện tốc độ phản hồi 40%)._
6.  **"The user session doesn't refresh automatically, which causes security warnings."** _(Session của user không tự động reload, điều này gây ra các cảnh báo bảo mật)._
7.  **"We resolved the memory leak, which stabilized the server load."** _(Chúng tôi đã sửa xong lỗi rò rỉ bộ nhớ, điều này làm ổn định tải của server)._
8.  **"The payment portal went down, which resulted in aborted user checkouts."** _(Cổng thanh toán bị sập, dẫn đến việc người dùng bị hủy checkout)._
9.  **"The package was upgraded yesterday, which introduced a breaking dependency."** _(Package được nâng cấp hôm qua, điều này gây ra lỗi tương thích)._
10. **"We moved our assets to a CDN, which dramatically decreased initial load times."** _(Chúng tôi chuyển asset sang CDN, nhờ đó giảm đáng kể thời gian tải trang đầu tiên)._

## 5. Bảng so sánh nhanh: Đầy đủ vs Rút gọn

| Mệnh đề đầy đủ                              | Bản rút gọn tự nhiên                     | Nghĩa tiếng Việt             |
| :------------------------------------------ | :--------------------------------------- | :--------------------------- |
| The PR **that contains** the bug...         | The PR **containing** the bug...         | PR có chứa lỗi...            |
| The issue **which was reported** by user... | The issue **reported** by the user...    | Lỗi được báo cáo bởi user... |
| The API **that runs** in the background...  | The API **running** in the background... | API chạy ngầm...             |
| The server **which is hosted** on AWS...    | The server **hosted** on AWS...          | Server được host trên AWS... |
| The framework **which was chosen**...       | The framework **chosen**...              | Framework được chọn...       |

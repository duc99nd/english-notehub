# Kể chuyện bằng dữ liệu

## Trình bày dữ liệu có sức ảnh hưởng

Kể chuyện bằng dữ liệu kết hợp số liệu, hình ảnh và câu chuyện để thuyết phục khán giả. Từ vựng đúng giúp insights của bạn đáng nhớ.

> **Pattern**: `The data reveals/shows/indicates + [insight]`

### Thuật ngữ kể chuyện dữ liệu chính

| Tiếng Anh             | Tiếng Việt           |
| --------------------- | -------------------- |
| upward trend          | xu hướng đi lên      |
| downward trend        | xu hướng đi xuống    |
| underscore            | nhấn mạnh            |
| reveal                | tiết lộ, cho thấy    |
| serve as an indicator | đóng vai trò chỉ báo |
| key metric            | số liệu quan trọng   |

## Cụm từ mẫu

| Tiếng Anh                                    | Tiếng Việt                                       |
| -------------------------------------------- | ------------------------------------------------ |
| The data reveals a clear upward trend.       | Dữ liệu cho thấy xu hướng tăng rõ rệt.           |
| Our findings underscore the need for action. | Phát hiện nhấn mạnh sự cần thiết phải hành động. |
| This metric serves as a key indicator.       | Số liệu này là chỉ báo quan trọng.               |

## Mẹo kể chuyện

1. **Bắt đầu bằng insight**, không phải dữ liệu
2. **Dùng so sánh** để số liệu có ý nghĩa
3. **Thêm ngữ cảnh** về lý do xu hướng quan trọng
4. **Kết thúc bằng lời kêu gọi hành động**

# Ngữ pháp C1 tinh tế

## Câu điều kiện hỗn hợp

Câu điều kiện hỗn hợp kết hợp tham chiếu thời gian quá khứ và hiện tại.

> **Mẫu A**: `Điều kiện quá khứ → Kết quả hiện tại`
> **Mẫu B**: `Điều kiện hiện tại → Kết quả quá khứ`

| Loại hỗn hợp       | Ví dụ                                       | Ý nghĩa                            |
| ------------------ | ------------------------------------------- | ---------------------------------- |
| Quá khứ → Hiện tại | Nếu tôi đã học luật, giờ tôi sẽ là luật sư. | Sai lầm quá khứ, kết quả hiện tại  |
| Hiện tại → Quá khứ | Nếu tôi dũng cảm hơn, tôi đã lên tiếng.     | Đặc điểm hiện tại, kết quả quá khứ |

## Đảo ngữ điều kiện (trang trọng)

Văn viết học thuật và điều hành trang trọng thường đảo ngữ câu điều kiện.

> **Pattern**: `Were/Had/Should + chủ ngữ + ...`

| Dạng đảo ngữ                     | Dạng chuẩn                     |
| -------------------------------- | ------------------------------ |
| Were we to launch in Q1, ...     | If we launched in Q1, ...      |
| Had the board approved, ...      | If the board had approved, ... |
| Should circumstances change, ... | If circumstances change, ...   |

## Modal perfect để suy đoán quá khứ

> **Pattern**: `modal + have + past participle (quá khứ phân từ)`

| Modal       | Chức năng                   | Ví dụ                                 |
| ----------- | --------------------------- | ------------------------------------- |
| must have   | Suy luận (quá khứ)          | Anh ấy hẳn đã rời đi sớm.             |
| might have  | Khả năng (quá khứ)          | Chúng tôi có thể đã bỏ lỡ hạn chót.   |
| could have  | Khả năng/năng lực (quá khứ) | Chúng tôi đã có thể làm tốt hơn.      |
| should have | Hối tiếc (quá khứ)          | Chúng tôi lẽ ra nên thông báo cho họ. |
| would have  | Giả định (quá khứ)          | Tôi sẽ đã đồng ý.                     |

## Câu chẻ để nhấn mạnh

> **Mẫu A**: `What + mệnh đề + is + [trọng tâm]`
> **Mẫu B**: `It + be + [trọng tâm] + that + mệnh đề`

| Mẫu                                     | Ví dụ                                                   |
| --------------------------------------- | ------------------------------------------------------- |
| What we need is more time.              | Điều chúng ta cần là thêm thời gian.                    |
| It is the methodology that concerns us. | Chính phương pháp luận là điều khiến chúng tôi lo ngại. |

## Ngôn ngữ tạo khoảng cách

Hedge học thuật sử dụng **tạo khoảng cách** để thể hiện sự tách rời khỏi tuyên bố.

> **Pattern**: `It is [tính từ] that + mệnh đề` hoặc `There appears to be + danh từ`

| Dạng                  | Ví dụ                             |
| --------------------- | --------------------------------- |
| It appears that...    | Có vẻ như dữ liệu đã bị hiểu sai. |
| There seems to be...  | Có vẻ có một mô hình.             |
| It would seem that... | Có vẻ như xu hướng đã đảo ngược.  |

## Bài tập: Chuyển đổi

1. "Nếu chúng tôi đã ra mắt sớm hơn, giờ chúng tôi sẽ thống trị thị trường." → Câu điều kiện hỗn hợp
2. "Nếu bạn cần giúp, hãy gọi tôi." → Đảo ngữ điều kiện
3. "Có thể họ đã bỏ lỡ cuộc họp." → Modal perfect

# Tán gẫu

## Tán gẫu là gì?

Tán gẫu là cuộc trò chuyện thông thường về những chủ đề hàng ngày. Nó giúp xây dựng mối quan hệ.

> **Mẫu câu**: `Nice [topic], isn't it?`

## Các chủ đề an toàn

| Tiếng Anh   | Tiếng Việt  |
| ----------- | ----------- |
| the weather | thời tiết   |
| the weekend | cuối tuần   |
| a movie     | một bộ phim |
| food        | đồ ăn       |
| travel      | du lịch     |

## Bắt đầu cuộc trò chuyện

| Tiếng Anh                        | Tiếng Việt                         |
| -------------------------------- | ---------------------------------- |
| Nice weather today, isn't it?    | Trời đẹp hôm nay, phải không?      |
| How was your weekend?            | Cuối tuần của bạn thế nào?         |
| Did you see the game last night? | Bạn có xem trận đấu tối qua không? |
| Have you tried this restaurant?  | Bạn đã thử nhà hàng này chưa?      |

## Tiếp tục cuộc trò chuyện

| Tiếng Anh             | Tiếng Việt          |
| --------------------- | ------------------- |
| Me too!               | Tôi cũng vậy!       |
| That's great!         | Tuyệt vời!          |
| Really? Tell me more. | Thật à? Kể thêm đi. |
| I agree.              | Tôi đồng ý.         |

## Những chủ đề nên tránh

- Tiền lương và tiền bạc
- Tuổi tác
- Quan điểm chính trị
- Niềm tin tôn giáo
- Vấn đề cá nhân

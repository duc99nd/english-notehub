# Thức ăn & Đồ uống

## Thức ăn phổ biến

| Tiếng Anh | Tiếng Việt | Loại          |
| --------- | ---------- | ------------- |
| rice      | cơm        | thức ăn chính |
| bread     | bánh mì    | bữa sáng      |
| chicken   | thịt gà    | thịt          |
| beef      | thịt bò    | thịt          |
| fish      | cá         | hải sản       |
| egg       | trứng      | protein       |
| vegetable | rau        | rau củ        |
| fruit     | trái cây   | trái cây      |
| noodle    | mì / phở   | tinh bột      |
| salad     | salad      | rau           |
| soup      | canh / súp | món nước      |

## Đồ uống phổ biến

| Tiếng Anh | Tiếng Việt |
| --------- | ---------- |
| water     | nước       |
| coffee    | cà phê     |
| tea       | trà        |
| milk      | sữa        |
| juice     | nước ép    |
| soda      | nước ngọt  |

## Dùng "I like / I don't like"

> **Mẫu câu**: `I like [food].` / `I don't like [food].`

### Ví dụ

| Tiếng Anh          | Tiếng Việt          |
| ------------------ | ------------------- |
| I like rice.       | Tôi thích cơm.      |
| I don't like fish. | Tôi không thích cá. |
| She likes coffee.  | Cô ấy thích cà phê. |

## Dùng "I would like"

Để gọi món một cách lịch sự, dùng **"I would like"**:

> **Mẫu câu**: `I would like some [food], please.`

### Ví dụ

| Tiếng Anh                           | Tiếng Việt                        |
| ----------------------------------- | --------------------------------- |
| I would like some rice, please.     | Tôi muốn gọi cơm ạ.               |
| I would like a cup of coffee.       | Tôi muốn gọi một ly cà phê.       |
| We would like two bottles of water. | Chúng tôi muốn gọi hai chai nước. |

## Ở nhà hàng

Những câu hữu ích khi gọi món:

| Tiếng Anh                   | Tiếng Việt                     |
| --------------------------- | ------------------------------ |
| Can I see the menu, please? | Tôi có thể xem thực đơn không? |
| What do you recommend?      | Bạn giới thiệu món gì?         |
| I would like...             | Tôi muốn gọi...                |
| The bill, please.           | Tính tiền ạ.                   |

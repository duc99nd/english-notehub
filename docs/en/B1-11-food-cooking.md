# Food & Cooking

## Essential Cooking Vocabulary

When cooking or talking about food, you need words for ingredients, methods, and kitchen items.

> **Pattern**: `First, you need to [verb] the [ingredient]. Then, [action].`

## Common Ingredients

|                | English         | Vietnamese |
| -------------- | --------------- | ---------- |
| vegetables     | rau củ          |
| fruits         | trái cây        |
| meat           | thịt            |
| poultry        | gia cầm         |
| seafood        | hải sản         |
| dairy products | sản phẩm từ sữa |
| grains         | ngũ cốc         |
| spices         | gia vị          |

## Cooking Methods

|           | English      | Vietnamese |
| --------- | ------------ | ---------- |
| to boil   | đun sôi      |

| to steam  | hấp          |

|                   | English       | Vietnamese |
| ----------------- | ------------- | ---------- |
| to chop           | thái, băm     |
| to slice          | thái lát mỏng |
| to peel           | gọt vỏ        |
| to grate          | nạo           |
| to mix / to blend | trộn / xay    |
| to pour           | đổ            |
| to stir-fry       | xào           |
| to knead          | nhào bột      |

## Useful Cooking Phrases

> "I'm going to cook pasta for dinner tonight."
> "First, you need to chop the vegetables."
> "Add the ingredients one at a time."
> "Let it simmer for 20 minutes."
> "Don't forget to season with salt and pepper."

## Practice lab

### Notice the language

Read the situation, then listen to the model once for meaning and once for phrasing.

> **Colleague:** How would you handle **food & cooking** in this situation?
>
> **You:** I'm going to cook pasta for dinner tonight.

Notice what the response does before you copy its wording: it gives the listener a clear point, enough context, and a usable next step.

> **Pattern**: clear point + concrete detail or reason + appropriate next step

# Travel & Transport

## Essential Travel Vocabulary

When you travel, you need to know words for different types of transport and travel activities.

> **Pattern**: `I'm going to [destination] by [transport].`

## Types of Transport

|                | English       | Vietnamese |
| -------------- | ------------- | ---------- |
| flight         | chuyến bay    |
| train          | tàu hỏa       |
| bus            | xe buýt       |
| taxi / cab     | taxi          |
| car            | ô tô          |
| bicycle / bike | xe đạp        |
| ferry          | phà           |
| cruise         | du thuyền     |
| subway / metro | tàu điện ngầm |

## Travel Activities

|                      | English              | Vietnamese |
| -------------------- | -------------------- | ---------- |
| to book / to reserve | đặt (vé, phòng)      |
| to check in          | làm thủ tục check-in |
| to board             | lên máy bay/tàu      |
| to take off          | cất cánh             |
| to land              | hạ cánh              |
| to depart            | khởi hành            |
| to arrive            | đến nơi              |
| to delay             | bị trễ               |
| to cancel            | bị hủy               |

## Useful Travel Phrases

> "I'm planning a trip to [city]."
> "I need to renew my passport."
> "Can you tell me how to get to the train station?"
> "What time does the next bus depart?"
> "Is there a direct flight?"
> "I'd like to book a window seat."

## At the Airport / Train Station

- `check-in desk` — quầy làm thủ tục
- `departure lounge` — phòng chờ khởi hành
- `boarding pass` — thẻ lên máy bay
- `luggage / baggage` — hành lý
- `to miss a flight` — lỡ chuyến bay
- `to catch a train` — kịp tàu

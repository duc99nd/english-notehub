# Advanced C1 Grammar

## Inversion for emphasis

Inversion places the verb before the subject to add emphasis. It is common after negative adverbials.

> **Pattern**: `Negative adverbial + auxiliary + subject + verb`

| English                                                               | Vietnamese                                                               |
| --------------------------------------------------------------------- | ------------------------------------------------------------------------ |
| Never have we seen such rapid growth.                                 | Chúng tôi chưa bao giờ thấy tăng trưởng nhanh như vậy.                   |
| Hardly had the meeting begun when the fire alarm rang.                | Cuộc họp vừa bắt đầu thì chuông báo cháy kêu.                            |
| Not only did the merger succeed, but it exceeded expectations.        | Không chỉ thương vụ thành công, mà còn vượt kỳ vọng.                     |
| Under no circumstances should confidential data be shared externally. | Trong bất kỳ trường hợp nào, dữ liệu bí mật không được chia sẻ ra ngoài. |

## Subjunctive mood

The subjunctive expresses wishes, hypotheticals, and strong recommendations.

> **Pattern**: `It is essential/crucial/imperative that + subject + base verb (subjunctive)`

| English                                                 | Vietnamese                                                 |
| ------------------------------------------------------- | ---------------------------------------------------------- |
| It is essential that every stakeholder **be** informed. | Điều cần thiết là mọi bên liên quan phải được thông báo.   |
| We recommend that the board **approve** the proposal.   | Chúng tôi khuyến nghị hội đồng phê duyệt đề xuất.          |
| It is vital that we **act** before the deadline.        | Điều quan trọng là chúng ta phải hành động trước hạn chót. |

## Cleft sentences for focus

> **Pattern A**: `What + clause + is/was + [focus]`
> **Pattern B**: `It + be + [focus] + that/who + clause`

| Pattern                                          | Example                                           |
| ------------------------------------------------ | ------------------------------------------------- |
| What concerns us is the timeline.                | Điều khiến chúng tôi lo ngại là tiến độ.          |
| It was the CFO who ultimately approved the deal. | Chính CFO là người cuối cùng phê duyệt thương vụ. |

## Participle clauses (advanced)

> **Pattern**: `Having/V-ed + [clause]`

| English                                            | Vietnamese                                            |
| -------------------------------------------------- | ----------------------------------------------------- |
| Having reviewed the data, we recommend approval.   | Sau khi xem xét dữ liệu, chúng tôi đề xuất phê duyệt. |
| Considered from all angles, the proposal is sound. | Xét từ mọi góc, đề xuất là hợp lý.                    |

## Cleft vs. inversion

| Device      | Use                                        |
| ----------- | ------------------------------------------ |
| Inversion   | Emphasize a negative/limiting adverbial    |
| Cleft       | Focus on one specific element              |
| Subjunctive | Express hypothetical/strong recommendation |

## Learning outcome

## Scenario practice

### Situation

Explain a fictional disruption strategy using inversion, correlative emphasis, and a formal recommendation while keeping causality precise.

> **Training note:** This situation and its details are fictional. They are designed for language practice, not presented as a real event, policy, study, or legal interpretation.

### Controlled practice

Take two example sentences from the lesson. Transform the first with the target structure, then revise the second to change emphasis or level of certainty without changing the core facts.

### Guided task

Write 65–200 words for the situation. Use the target structure at least twice, underline those choices, and add one sentence explaining how one structure changes emphasis, time, condition, or certainty.

### Model response

> **Draft:** Had we anticipated the disruption, we would have diversified earlier. Not only did the merger create synergies, but it also expanded our reach. It is imperative that every stakeholder be informed of the changes.
>
> **Language choice:** I select only the evidence that changes the decision, qualify any projection that depends on an assumption, and make ownership visible. A different stakeholder could reasonably prefer another option, so the response identifies the condition that would justify revisiting the recommendation. Other well-supported responses are possible.

### Why the model works

The model shows one defensible route through the task; it is not a script to memorize. Compare its task completion, language accuracy, audience fit, and clarity with your response, then revise once.

### Transfer task

Rewrite one sentence for a less formal leadership update. Keep the target language, but change the details and register needed for the new context.

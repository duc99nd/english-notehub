# Review Unit 2

## What we learned

In Unit 2, you built C1 financial and analytical skills:

1. **Investor Relations** — IR vocabulary and earnings calls
2. **Advanced Grammar** — Inversion, subjunctive, cleft sentences
3. **Policy Reading** — Interpreting obligation levels
4. **Executive Summary** — BLUF structure

## Quick review

### Investor relations vocabulary

| Term        | Meaning                    |
| ----------- | -------------------------- |
| EPS         | Earnings per share         |
| Fiscal year | Company financial year     |
| Guidance    | Forward-looking forecast   |
| Consensus   | Average analyst estimate   |
| Outperform  | Exceed market expectations |

### Advanced grammar patterns

| Pattern           | Example                                             |
| ----------------- | --------------------------------------------------- |
| Inversion         | Never have we seen such growth.                     |
| Subjunctive       | It is essential that every stakeholder be informed. |
| Cleft             | What concerns us is the timeline.                   |
| Participle clause | Having reviewed the data, we recommend approval.    |

### Policy obligation levels

| Level       | Words        |
| ----------- | ------------ |
| Mandatory   | must / shall |
| Prohibited  | shall not    |
| Permitted   | may          |
| Recommended | should       |

### Executive summary structure

| Element          | Purpose                          |
| ---------------- | -------------------------------- |
| Recommendation   | Bold one-line ask                |
| Context          | 1-2 sentences                    |
| Supporting facts | 2-3 data points                  |
| Risk             | One key risk and mitigation      |
| Ask              | Specific action by specific date |

## Practice lab

### Notice the language

Read the situation, then listen to the model once for meaning and once for phrasing.

> **Colleague:** How would you handle **review unit 2** in this situation?
>
> **You:** Let's review Unit 2.

Notice what the response does before you copy its wording: it gives the listener a clear point, enough context, and a usable next step.

> **Pattern**: clear point + concrete detail or reason + appropriate next step

### Your turn

Complete one integrated response for a colleague, client, and senior stakeholder using language from at least three lessons in this unit.

### Model response

> Let's review Unit 2. You can now communicate effectively with investors. You can use advanced C1 grammar structures. You can read policy documents. You can write executive summaries.

The model is one possible response, not a script you must memorize. Compare its purpose, level of detail, and tone with your version, then revise once.

### Register switch

Rewrite your response twice: first for a trusted teammate, then for a client or senior stakeholder. Keep the underlying message the same while changing directness, context, and the amount of explanation. Identify one phrase you softened, one detail you made explicit, and one assumption you removed.

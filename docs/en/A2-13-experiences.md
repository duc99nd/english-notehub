# Experiences

## Present perfect for life experiences

Use the present perfect to talk about things you have done in your life. We often don't say exactly when.

> **Pattern**: `Subject + have/has + past participle (V3)`

| Subject          | Auxiliary |
| ---------------- | --------- |
| I, you, we, they | have      |
| He, she, it      | has       |

## Common time expressions

| Expression                 | Example                          |
| -------------------------- | -------------------------------- |
| ever                       | "Have you ever tried sushi?"     |
| never                      | "I have never eaten snails."     |
| already                    | "I have already finished."       |
| yet                        | "I haven't finished yet."        |
| once / twice / three times | "I have visited twice."          |
| for + time                 | "I have lived here for 5 years." |
| since + time               | "I have worked here since 2020." |

## Examples

| English                      | Vietnamese                         |
| ---------------------------- | ---------------------------------- |
| I have visited Japan.        | Tôi đã từng đến Nhật Bản.          |
| She has tried sushi once.    | Cô ấy đã thử sushi một lần.        |
| We have never seen snow.     | Chúng tôi chưa bao giờ thấy tuyết. |
| Have you ever been to Paris? | Bạn đã từng đến Paris chưa?        |

## Regular past participles (V3)

| Verb (V1) | Past Participle (V3) |
| --------- | -------------------- |
| visit     | visited              |
| try       | tried                |
| finish    | finished             |
| live      | lived                |
| work      | worked               |
| play      | played               |

## Irregular past participles

| Verb (V1) | Past Participle (V3) |
| --------- | -------------------- |
| be        | been                 |
| do        | done                 |
| eat       | eaten                |
| see       | seen                 |
| go        | gone                 |
| have      | had                  |

### Notice the language

Read the situation, then listen to the model once for meaning and once for phrasing.

Notice what the response does before you copy its wording: it gives the listener a clear point, enough context, and a usable next step.

> **Pattern**: clear point + concrete detail or reason + appropriate next step

# Phone Call

## Answering the phone

When you answer a phone call, you should:

> **Pattern**: `Hello, this is [name] speaking.`

### Examples

| English                            | Vietnamese                            |
| ---------------------------------- | ------------------------------------- |
| Hello, this is Anna speaking.      | Xin chào, tôi là Anna.                |
| Good morning, John Smith speaking. | Chào buổi sáng, tôi là John Smith.    |
| Hello, how can I help you?         | Xin chào, tôi có thể giúp gì cho bạn? |

## Making a phone call

When you call someone:

| English                | Vietnamese                             |
| ---------------------- | -------------------------------------- |
| Can I speak to [name]? | Tôi có thể nói chuyện với [tên] không? |
| Is [name] available?   | [Tên] có ở đây không?                  |
| I'm calling about...   | Tôi gọi về việc...                     |

## Taking a message

If the person is not available:

| English                                | Vietnamese                        |
| -------------------------------------- | --------------------------------- |
| Can I take a message?                  | Tôi có thể nhận lời nhắn không?   |
| Could you call back later?             | Bạn có thể gọi lại sau không?     |
| He/She is not available at the moment. | Anh/cô ấy không có ở đây bây giờ. |

## Useful phrases

| English                  | Vietnamese                      |
| ------------------------ | ------------------------------- |
| I'm sorry, wrong number. | Xin lỗi, số sai.                |
| The line is bad.         | Đường line kết nối không tốt.   |
| I'll put you through.    | Tôi sẽ chuyển cuộc gọi cho bạn. |
| Hold on, please.         | Xin đợi một chút.               |

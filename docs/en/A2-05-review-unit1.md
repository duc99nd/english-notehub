# Review Unit 1

## What we learned

In Unit 1, you learned four important topics:

1. **Asking for Help** - Polite phrases to request assistance
2. **Daily Routine** - Present simple tense for habits
3. **Comparatives** - Comparing things with -er and more
4. **Past Events** - Past simple tense for completed actions

## Quick review

### Asking for Help

| English                    | When to use             |
| -------------------------- | ----------------------- |
| Could you help me?         | Polite request          |
| Would you mind helping me? | Very polite             |
| Sorry to bother you        | Apologize before asking |

### Daily Routine

- Use **present simple** for habits
- Add **-s/-es** with he, she, it
- Time words: every day, usually, always

### Comparatives

- Short adjectives: adjective + **-er** + than
- Long adjectives: **more** + adjective + than
- Irregular: good → better, bad → worse

### Past Events

- Regular verbs: add **-ed**
- Irregular verbs: memorize the forms
- Was/Were for past of "to be"

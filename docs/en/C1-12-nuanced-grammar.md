# Nuanced C1 Grammar

## Mixed conditionals

Mixed conditionals combine past and present time references.

> **Pattern A**: `Past condition → Present result`
> **Pattern B**: `Present condition → Past result`

| Mixed Type | Example | Meaning |
| --- | --- | --- |
| Past → Present | If I had studied law, I would be a lawyer now. | Past mistake, present result |
| Present → Past | If I were braver, I would have spoken up. | Present trait, past result |

## Inverted conditionals (formal)

Formal academic and executive writing often inverts conditionals.

> **Pattern**: `Were/Had/Should + subject + ...`

| Inverted Form | Standard Form |
| --- | --- |
| Were we to launch in Q1, ... | If we launched in Q1, ... |
| Had the board approved, ... | If the board had approved, ... |
| Should circumstances change, ... | If circumstances change, ... |

## Modal perfect for past speculation

> **Pattern**: `modal + have + past participle`

| Modal | Function | Example |
| --- | --- | --- |
| must have | Deduction (past) | He must have left early. |
| might have | Possibility (past) | We might have missed the deadline. |
| could have | Ability/possibility (past) | We could have done better. |
| should have | Regret (past) | We should have informed them. |
| would have | Hypothetical (past) | I would have agreed. |

## Cleft sentences for emphasis

> **Pattern A**: `What + clause + is + [focus]`
> **Pattern B**: `It + be + [focus] + that + clause`

| Pattern | Example |
| --- | --- |
| What we need is more time. | Điều chúng ta cần là thêm thời gian. |
| It is the methodology that concerns us. | Chính phương pháp luận là điều khiến chúng tôi lo ngại. |

## Distancing language

Academic hedging uses **distancing** to show detachment from claims.

> **Pattern**: `It is [adjective] that + clause` or `There appears to be + noun`

| Form | Example |
| --- | --- |
| It appears that... | It appears that the data was misinterpreted. |
| There seems to be... | There seems to be a pattern. |
| It would seem that... | It would seem that the trend has reversed. |

# Nuanced C1 Grammar

## Mixed conditionals

Mixed conditionals combine past and present time references.

> **Pattern A**: `Past condition → Present result`
> **Pattern B**: `Present condition → Past result`

| Mixed Type     | Example                                        | Meaning                      |
| -------------- | ---------------------------------------------- | ---------------------------- |
| Past → Present | If I had studied law, I would be a lawyer now. | Past mistake, present result |
| Present → Past | If I were braver, I would have spoken up.      | Present trait, past result   |

## Inverted conditionals (formal)

Formal academic and executive writing often inverts conditionals.

> **Pattern**: `Were/Had/Should + subject + ...`

| Inverted Form                    | Standard Form                  |
| -------------------------------- | ------------------------------ |
| Were we to launch in Q1, ...     | If we launched in Q1, ...      |
| Had the board approved, ...      | If the board had approved, ... |
| Should circumstances change, ... | If circumstances change, ...   |

## Modal perfect for past speculation

> **Pattern**: `modal + have + past participle`

| Modal       | Function                   | Example                            |
| ----------- | -------------------------- | ---------------------------------- |
| must have   | Deduction (past)           | He must have left early.           |
| might have  | Possibility (past)         | We might have missed the deadline. |
| could have  | Ability/possibility (past) | We could have done better.         |
| should have | Regret (past)              | We should have informed them.      |
| would have  | Hypothetical (past)        | I would have agreed.               |

## Cleft sentences for emphasis

> **Pattern A**: `What + clause + is + [focus]`
> **Pattern B**: `It + be + [focus] + that + clause`

| Pattern                                 | Example                                                 |
| --------------------------------------- | ------------------------------------------------------- |
| What we need is more time.              | Điều chúng ta cần là thêm thời gian.                    |
| It is the methodology that concerns us. | Chính phương pháp luận là điều khiến chúng tôi lo ngại. |

## Distancing language

Academic hedging uses **distancing** to show detachment from claims.

> **Pattern**: `It is [adjective] that + clause` or `There appears to be + noun`

| Form                  | Example                                      |
| --------------------- | -------------------------------------------- |
| It appears that...    | It appears that the data was misinterpreted. |
| There seems to be...  | There seems to be a pattern.                 |
| It would seem that... | It would seem that the trend has reversed.   |

2. "If you need help, call me." → Inverted conditional
3. "Maybe they missed the meeting." → Modal perfect

## Learning outcome

By the end of this lesson, you can produce a connected response about nuanced c1 grammar, use the target structure accurately, and explain one effect of that choice.

## Scenario practice

### Situation

Compare fictional market-entry scenarios with different timing and evidence. Use inversion while distinguishing condition, probability, and contingency.

> **Training note:** This situation and its details are fictional. They are designed for language practice, not presented as a real event, policy, study, or legal interpretation.

### Controlled practice

Take two example sentences from the lesson. Transform the first with the target structure, then revise the second to change emphasis or level of certainty without changing the core facts.

### Guided task

Write 65–200 words for the situation. Use the target structure at least twice, underline those choices, and add one sentence explaining how one structure changes emphasis, time, condition, or certainty.

### Model response

> **Draft:** Had the board approved the proposal earlier, we would be operating internationally today. Were we to launch in Q1, we would capture the early adopters. Should circumstances change, we are prepared to pivot.
>
> **Language choice:** I select only the evidence that changes the decision, qualify any projection that depends on an assumption, and make ownership visible. A different stakeholder could reasonably prefer another option, so the response identifies the condition that would justify revisiting the recommendation. Other well-supported responses are possible.

### Why the model works

The model shows one defensible route through the task; it is not a script to memorize. Compare its task completion, language accuracy, audience fit, and clarity with your response, then revise once.

### Transfer task

Revise the recommendation when one condition becomes unlikely. Keep the target language, but change the details and register needed for the new context.

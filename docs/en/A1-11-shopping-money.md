# Shopping & Money

## Shopping Places

| English        | Vietnamese           | What you buy         |
| -------------- | -------------------- | -------------------- |
| supermarket    | siêu thị             | food, daily items    |
| market         | chợ                  | fresh food, clothes  |
| shopping mall  | trung tâm thương mại | clothes, electronics |
| bookstore      | hiệu sách            | books                |
| pharmacy       | nhà thuốc            | medicine             |
| clothing store | cửa hàng quần áo     | clothes              |

## How to ask about prices

> **Pattern**: `How much is this?` (for one item)
>
> **Pattern**: `How much are these?` (for multiple items)

### Examples

| English                    | Vietnamese                   |
| -------------------------- | ---------------------------- |
| How much is this shirt?    | Áo này bao nhiêu tiền?       |
| How much is this book?     | Cuốn sách này bao nhiêu?     |
| How much are these apples? | Những quả táo này bao nhiêu? |

## Shopping phrases

| English                            | Vietnamese                       |
| ---------------------------------- | -------------------------------- |
| I would like to buy this.          | Tôi muốn mua cái này.            |
| Can I pay by card?                 | Tôi có thể trả bằng thẻ không?   |
| Do you have a smaller size?        | Bạn có kích thước nhỏ hơn không? |
| Do you have this in another color? | Bạn có màu khác không?           |
| Can I try this on?                 | Tôi có thể thử không?            |
| Where is the fitting room?         | Phòng thay đồ ở đâu?             |

## Comparing prices

| English                         | Vietnamese                     |
| ------------------------------- | ------------------------------ |
| This is too expensive.          | Cái này quá đắt.               |
| Do you have a discount?         | Bạn có giảm giá không?         |
| Can you give me a better price? | Bạn có thể giảm giá hơn không? |

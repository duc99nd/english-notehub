# Cultural Nuances

## Communicating across cultures

Cross-cultural communication requires sensitivity to indirect styles, hierarchy, and context. These phrases help you navigate diverse workplaces.

> **Pattern**: `In some cultures, [behavior] is considered [perception]`

### Cultural awareness vocabulary

| English                    | Vietnamese          |
| -------------------------- | ------------------- |
| read between the lines     | đọc giữa các dòng   |
| rapport                    | quan hệ tốt         |
| hierarchy                  | hệ thống cấp bậc    |
| direct feedback            | phản hồi trực tiếp  |
| implicit / explicit        | hàm ẩn / rõ ràng    |
| high-context / low-context | ngữ cảnh cao / thấp |

## Cultural differences

| Aspect              | High-context cultures | Low-context cultures |
| ------------------- | --------------------- | -------------------- |
| Communication style | Indirect, implicit    | Direct, explicit     |
| Decision-making     | Group consensus       | Individual authority |
| Feedback            | Subtle, face-saving   | Open, frank          |

## Useful phrases

- "Building rapport takes time across different cultural contexts."
- "It's important to read between the lines during international negotiations."
- "In some cultures, direct feedback is considered rude."

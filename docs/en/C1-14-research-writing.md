# Research Writing

## The IMRaD structure

Academic research papers follow the **IMRaD** structure:

| Section      | Purpose                       | Length        |
| ------------ | ----------------------------- | ------------- |
| Abstract     | Summary of entire paper       | 150-250 words |
| Introduction | Context and research question | 10-15%        |
| Methodology  | How the study was conducted   | 10-15%        |
| Results      | What was found                | 20-25%        |
| Discussion   | What the findings mean        | 25-30%        |

## Abstract structure

> **Pattern**: `Background + Purpose + Method + Results + Conclusion`

| Component  | Question Answered                 |
| ---------- | --------------------------------- |
| Background | What is the context?              |
| Purpose    | What does this study investigate? |
| Method     | How was it conducted?             |
| Results    | What was found?                   |
| Conclusion | What does it mean?                |

## Introduction: the funnel

Move from broad to narrow:

1. **Topic sentence** — broad context
2. **Narrowing** — specific issue
3. **Gap** — what is missing in current knowledge
4. **Purpose statement** — what this paper addresses
5. **Thesis** — your main argument

## Methodology language

> **Pattern**: `The study employs / adopts / utilizes + [method]`

| Verb    | Formality   |
| ------- | ----------- |
| employs | Most formal |
| adopts  | Formal      |
| uses    | Neutral     |
| applies | Formal      |

## Results: passive voice for objectivity

> **Pattern**: `It was [verb-ed] that...` or `A significant [noun] was [verb-ed]`

| Active                  | Academic passive                     |
| ----------------------- | ------------------------------------ |
| We found a correlation. | A significant correlation was found. |
| The data shows...       | The data were analyzed using...      |

## Discussion: hedging and limitations

| Phrase                                 | Purpose              |
| -------------------------------------- | -------------------- |
| "These findings suggest..."            | Interpret cautiously |
| "However, this study is limited by..." | Acknowledge limits   |
| "Future research should..."            | Suggest next steps   |
| "In conclusion,..."                    | Summarize            |

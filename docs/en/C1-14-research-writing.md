# Research Writing

## The IMRaD structure

Academic research papers follow the **IMRaD** structure:

| Section      | Purpose                       | Length        |
| ------------ | ----------------------------- | ------------- |
| Abstract     | Summary of entire paper       | 150-250 words |
| Introduction | Context and research question | 10-15%        |
| Methodology  | How the study was conducted   | 10-15%        |
| Results      | What was found                | 20-25%        |
| Discussion   | What the findings mean        | 25-30%        |

## Abstract structure

> **Pattern**: `Background + Purpose + Method + Results + Conclusion`

| Component  | Question Answered                 |
| ---------- | --------------------------------- |
| Background | What is the context?              |
| Purpose    | What does this study investigate? |
| Method     | How was it conducted?             |
| Results    | What was found?                   |
| Conclusion | What does it mean?                |

## Introduction: the funnel

Move from broad to narrow:

1. **Topic sentence** — broad context
2. **Narrowing** — specific issue
3. **Gap** — what is missing in current knowledge
4. **Purpose statement** — what this paper addresses
5. **Thesis** — your main argument

## Methodology language

> **Pattern**: `The study employs / adopts / utilizes + [method]`

| Verb    | Formality   |
| ------- | ----------- |
| employs | Most formal |
| adopts  | Formal      |
| uses    | Neutral     |
| applies | Formal      |

## Results: passive voice for objectivity

> **Pattern**: `It was [verb-ed] that...` or `A significant [noun] was [verb-ed]`

| Active                  | Academic passive                     |
| ----------------------- | ------------------------------------ |
| We found a correlation. | A significant correlation was found. |
| The data shows...       | The data were analyzed using...      |

## Discussion: hedging and limitations

| Phrase                                 | Purpose              |
| -------------------------------------- | -------------------- |
| "These findings suggest..."            | Interpret cautiously |
| "However, this study is limited by..." | Acknowledge limits   |
| "Future research should..."            | Suggest next steps   |
| "In conclusion,..."                    | Summarize            |

By the end of this lesson, you will be able to produce and revise a clear piece of writing about research writing for a defined audience.

## Practice lab

### Notice the language

Read the situation, then listen to the model once for meaning and once for phrasing.

> **Colleague:** How would you handle **research writing** in this situation?
>
> **You:** This paper examines the impact of remote work on productivity.

Notice what the response does before you copy its wording: it gives the listener a clear point, enough context, and a usable next step.

> **Pattern**: clear point + concrete detail or reason + appropriate next step

### Your turn

Write 80–120 words for a colleague, client, and senior stakeholder. State the purpose early, support it with a concrete detail, and finish with a clear next step.

### Model response

> This paper examines the impact of remote work on productivity. The methodology employs a mixed-methods approach. The findings indicate a statistically significant improvement in output.

The model is one possible response, not a script you must memorize. Compare its purpose, level of detail, and tone with your version, then revise once.

### Register switch

Rewrite your response twice: first for a trusted teammate, then for a client or senior stakeholder. Keep the underlying message the same while changing directness, context, and the amount of explanation. Identify one phrase you softened, one detail you made explicit, and one assumption you removed.

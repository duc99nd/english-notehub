# Work & Daily Routines

## Essential Work Vocabulary

When talking about your job, you need words for different aspects of work life.

> **Pattern**: `I work as a [profession]. I usually start at [time].`

## Jobs and Professions

|                   | English              | Vietnamese |
| ----------------- | -------------------- | ---------- |
| manager           | quản lý              |
| employee          | nhân viên            |
| colleague         | đồng nghiệp          |
| boss / supervisor | sếp / người giám sát |
| freelancer        | người làm tự do      |
| intern            | thực tập sinh        |
| consultant        | chuyên gia tư vấn    |

## Workplace Places

| to give a presentation | thuyết trình      |

## Useful Work Phrases

> "I usually start work at 9 AM."
> "I have a meeting with my manager this afternoon."
> "I need to finish this report by Friday."
> "Could you help me with this task?"
> "I'll get back to you on that."

## Work Schedule

- `full-time` — toàn thời gian
- `part-time` — bán thời gian
- `shift work` — làm việc theo ca
- `overtime` — tăng ca
- `remote work` — làm việc từ xa
- `hybrid` — kết hợp (văn phòng + từ xa)

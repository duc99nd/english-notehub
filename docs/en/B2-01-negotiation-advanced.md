# Advanced Negotiation Strategies

## Key negotiation idioms

Negotiation requires more than vocabulary — you need the right idioms to sound natural and professional.

> **Pattern**: `Let me run this by you...` — share something for quick feedback

### Essential negotiation phrases

| English                  | Vietnamese            |
| ------------------------ | --------------------- |
| run something by someone | chia sẻ để lấy ý kiến |
| find middle ground       | tìm điểm chung        |
| circle back              | quay lại bàn bạc      |
| buy in                   | đồng ý, ủng hộ        |
| deep dive                | đi sâu vào chi tiết   |

## Practical examples

**Running an idea by the team**

> "Let me run this proposal by you before I send it to the client. Does the pricing structure work for Q4?"

**Finding compromise**

> "We can't meet that deadline, but maybe we can find some middle ground — say, a two-week extension?"

**Seeking alignment**

> "Before we move forward, I want to make sure everyone has a chance to buy in on this approach."

**Scheduling a follow-up**

> "Let's circle back next Tuesday to finalize the terms. I'll send a summary in the meantime."

## When to use each phrase

- **run by**: Early in discussions, when you need quick input
- **middle ground**: When both sides need to give something up
- **circle back**: When a decision needs more time or information
- **buy in**: When you need team or stakeholder support
- **deep dive**: When you need detailed analysis before deciding

# Small Talk

## What is small talk?

Small talk is casual conversation about everyday topics. It helps build relationships.

> **Pattern**: `Nice [topic], isn't it?`

## Safe topics

| English     | Vietnamese  |
| ----------- | ----------- |
| the weather | thời tiết   |
| the weekend | cuối tuần   |
| a movie     | một bộ phim |
| food        | đồ ăn       |
| travel      | du lịch     |

## Starting conversations

| English                          | Vietnamese                         |
| -------------------------------- | ---------------------------------- |
| Nice weather today, isn't it?    | Trời đẹp hôm nay, phải không?      |
| How was your weekend?            | Cuối tuần của bạn thế nào?         |
| Did you see the game last night? | Bạn có xem trận đấu tối qua không? |
| Have you tried this restaurant?  | Bạn đã thử nhà hàng này chưa?      |

## Continuing conversations

| English               | Vietnamese          |
| --------------------- | ------------------- |
| Me too!               | Tôi cũng vậy!       |
| That's great!         | Tuyệt vời!          |
| Really? Tell me more. | Thật à? Kể thêm đi. |
| I agree.              | Tôi đồng ý.         |

## Topics to avoid

- Salary and money
- Age
- Political views
- Religious beliefs
- Personal problems

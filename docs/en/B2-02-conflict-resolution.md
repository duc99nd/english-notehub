# Conflict Resolution Grammar

## The passive voice for neutrality

In conflicts, passive voice removes blame and sounds more diplomatic.

> **Pattern**: `Subject + was/were + past participle` (by + agent)

### Active vs Passive

| Active                       | Passive                  |
| ---------------------------- | ------------------------ |
| They made the decision.      | The decision was made.   |
| Someone left out the budget. | The budget was left out. |
| They didn't consult us.      | We weren't consulted.    |

## Past perfect passive

Use this to describe actions that happened before the conflict.

> **Pattern**: `Subject + had been + past participle`

**Examples:**

- "The issue had been raised by three team members before the meeting."
- "The feature hadn't been tested properly."
- "They had been informed about the deadline."

## Inverted conditionals

For formal or written conflict resolution, invert the conditional.

> **Pattern**: `Had + subject + past participle...` (instead of "If + subject + had + past participle...")

### Examples

| Standard                             | Inverted (formal)                 |
| ------------------------------------ | --------------------------------- |
| If I had known, I would have helped. | Had I known, I would have helped. |
| If it had been raised earlier...     | Had it been raised earlier...     |
| If they had consulted us...          | Had they consulted us...          |

## Putting it together

> "The timeline was compressed without team input. If we had been consulted, the deadline would have been more realistic."

> "Had the issue been flagged in the sprint review, we could have addressed it before launch."

# Review Unit 3

## What We Learned

In Unit 3, you learned four important skills for everyday life:

1. **Food & Cooking** - Vocabulary for ingredients, cooking methods, and meals
2. **First & Second Conditionals** - Talking about real and imaginary situations
3. **Recipes & Menus** - Reading and understanding recipes and menus
4. **Blog Post or Review** - Writing reviews and sharing opinions

## Quick Review

### Food & Cooking Vocabulary

| Category | Examples                                     |
| -------- | -------------------------------------------- |
| Methods  | to boil, to fry, to bake, to steam, to grill |
| Actions  | to chop, to slice, to peel, to mix, to stir  |
| Meals    | breakfast, lunch, dinner, appetizer, dessert |

### Conditionals

| Type               | Structure                 | Use                        |
| ------------------ | ------------------------- | -------------------------- |
| First Conditional  | If + present, will + verb | Real and likely situations |
| Second Conditional | If + past, would + verb   | Imaginary situations       |

**Examples:**

- First: If it **rains**, I **will stay** home.
- Second: If I **won** the lottery, I **would travel**.

### Review Structure

1. Introduction: What you are reviewing
2. Body: Details and experiences
3. Conclusion: Recommendation (Overall, I would recommend...)

3. If I (were / was) rich, I (will / would) buy a yacht.

# Advanced Mixed Conditionals

## Third Conditional — past hypotheticals

The Third Conditional talks about imaginary past events and their imagined results.

> **Pattern**: `If + past perfect, would have + past participle`

| English                                                   | Vietnamese                                   |
| --------------------------------------------------------- | -------------------------------------------- |
| If I had studied harder, I would have passed the exam.    | Nếu tôi học chăm hơn, tôi đã đậu kỳ thi.     |
| If she had left earlier, she would have caught the train. | Nếu cô ấy đi sớm hơn, cô ấy đã kịp tàu.      |
| Had I known about the meeting, I would have attended.     | Giá mà tôi biết về cuộc họp, tôi đã tham dự. |

## Mixed Conditionals

Mixed conditionals connect a past cause with a present result, or vice versa.

> **Pattern A** (past → present): `If + past perfect, would + base verb`
> **Pattern B** (present → past): `If + past simple, would have + past participle`

| Pattern        | Example                                                         |
| -------------- | --------------------------------------------------------------- |
| Past → Present | If I had studied medicine, I would be a doctor now.             |
| Present → Past | If she were more experienced, she would have handled it better. |

## Common time markers

- Yesterday / last week / in 2020 → past hypothetical
- Now / today / currently → present result
- Always / every time → general truth

3. **Critical Reading** — Evaluating arguments
4. **Research Writing** — IMRaD structure

## Quick review

### Academic vocabulary and hedging

| Term | Meaning |
| --- | --- |
| paradigm | Model or framework |
| methodology | Research approach |
| empirical | Based on observation |
| literature | Existing research |
| findings | Research results |

| Hedge strength | Verbs |
| --- | --- |
| Strong | demonstrate, prove, establish |
| Medium | suggest, indicate, imply |
| Weak | appear, seem, tend |

### Nuanced grammar patterns

| Pattern | Example |
| --- | --- |
| Mixed conditional | If I had studied, I would be a doctor now. |
| Inverted conditional | Were we to launch, ... |
| Modal perfect | We should have informed them. |
| Cleft sentence | What we need is more time. |
| Distancing | It appears that... |

### Critical reading framework

| Step | Purpose |
| --- | --- |
| Identify claim | What is argued? |
| Examine evidence | What supports it? |
| Evaluate methodology | How was it gathered? |
| Identify assumptions | What is taken for granted? |
| Consider alternatives | What other explanations? |

### IMRaD research structure

| Section | Purpose |
| --- | --- |
| Abstract | 150-250 word summary |
| Introduction | Context and research question |
| Methodology | How conducted |
| Results | What found |
| Discussion | What it means |

# Review Unit 3

## What we learned

In Unit 3, you built academic research skills:

1. **Academic Discourse** — Vocabulary and hedging
2. **Nuanced Grammar** — Mixed conditionals, modal perfects, cleft
3. **Critical Reading** — Evaluating arguments
4. **Research Writing** — IMRaD structure

## Quick review

### Academic vocabulary and hedging

| Term        | Meaning              |
| ----------- | -------------------- |
| paradigm    | Model or framework   |
| methodology | Research approach    |
| empirical   | Based on observation |
| literature  | Existing research    |
| findings    | Research results     |

| Hedge strength | Verbs                         |
| -------------- | ----------------------------- |
| Strong         | demonstrate, prove, establish |
| Medium         | suggest, indicate, imply      |
| Weak           | appear, seem, tend            |

### Nuanced grammar patterns

| Pattern              | Example                                    |
| -------------------- | ------------------------------------------ |
| Mixed conditional    | If I had studied, I would be a doctor now. |
| Inverted conditional | Were we to launch, ...                     |
| Modal perfect        | We should have informed them.              |
| Cleft sentence       | What we need is more time.                 |
| Distancing           | It appears that...                         |

### Critical reading framework

| Step                  | Purpose                    |
| --------------------- | -------------------------- |
| Identify claim        | What is argued?            |
| Examine evidence      | What supports it?          |
| Evaluate methodology  | How was it gathered?       |
| Identify assumptions  | What is taken for granted? |
| Consider alternatives | What other explanations?   |

### IMRaD research structure

| Section      | Purpose                       |
| ------------ | ----------------------------- |
| Abstract     | 150-250 word summary          |
| Introduction | Context and research question |
| Methodology  | How conducted                 |
| Results      | What found                    |
| Discussion   | What it means                 |

## Learning outcome

By the end of this lesson, you can combine language from the unit to resolve a realistic task involving review unit 3 and justify one revision.

## Scenario practice

### Situation

Assess a fictional research claim from source to recommendation: define terms, qualify grammar, critique evidence, and write a concise abstract.

> **Training note:** This situation and its details are fictional. They are designed for language practice, not presented as a real event, policy, study, or legal interpretation.

### Controlled practice

Select language from at least three lessons in this unit. For each choice, note the job it performs: describe, connect, qualify, request, or conclude.

### Guided task

Write 65–200 words to complete the integrated task. Use material from at least three lessons, then annotate one revision that improved accuracy, tone, or clarity.

### Model response

> **Integrated response:** Let's review Unit 3. You can now use academic vocabulary and hedging. You can apply nuanced C1 grammar structures.
>
> **Revision note:** I select only the evidence that changes the decision, qualify any projection that depends on an assumption, and make ownership visible. A different stakeholder could reasonably prefer another option, so the response identifies the condition that would justify revisiting the recommendation. Other well-supported responses are possible.

### Why the model works

The model shows one defensible route through the task; it is not a script to memorize. Compare its task completion, language accuracy, audience fit, and clarity with your response, then revise once.

### Transfer task

Adapt the recommendation for an executive audience. Keep the target language, but change the details and register needed for the new context.

# Complex Sentence Structures

## Building sophisticated sentences

Complex sentences use subordinate clauses to add nuance and detail. Mastering these helps you sound polished and professional.

### Common subordinating conjunctions

| Conjunction                | Function   | Example                                          |
| -------------------------- | ---------- | ------------------------------------------------ |
| although / even though     | Contrast   | Although the deadline is tight, we will deliver. |
| because / since / as       | Cause      | Because of the delay, we need more time.         |
| while / whereas            | Comparison | She prefers remote, while he prefers the office. |
| if / unless                | Condition  | Unless we act now, we risk losing ground.        |
| when / once / as soon as   | Time       | Once approved, we will start.                    |
| given that / provided that | Condition  | Given the complexity, we need more resources.    |

## Inversion for emphasis

> **Pattern**: `Negative adverbial + auxiliary + subject + verb`

| English                                                          | Vietnamese                                                 |
| ---------------------------------------------------------------- | ---------------------------------------------------------- |
| Not only does it reduce costs, but it also improves scalability. | Không chỉ giảm chi phí, mà còn cải thiện khả năng mở rộng. |
| Hardly had I arrived when the meeting started.                   | Tôi vừa đến nơi thì cuộc họp bắt đầu.                      |

## Participle clauses

> **Pattern**: `V-ing/V-ed + [rest of sentence]`

- Given the complexity of the project, we recommend additional resources.
- Having reviewed the data, we agree with the proposal.
- Considered from all angles, the decision seems sound.

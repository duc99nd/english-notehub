# Asking for Help

## When you need assistance

In daily life, you will often need help. Learning to ask politely is important.

> **Pattern**: `Excuse me, could you help me with [something]?`

### Common phrases

| English                     | Vietnamese                      |
| --------------------------- | ------------------------------- |
| Could you help me, please?  | Bạn có thể giúp tôi được không? |
| Would you mind helping me?  | Bạn có phiền giúp tôi không?    |
| Sorry to bother you, but... | Xin lỗi đã làm phiền, nhưng...  |
| I need some help.           | Tôi cần giúp đỡ.                |

## Asking for directions

When you are lost, you can ask:

- `Excuse me, how do I get to the train station?`
- `Can you tell me where the bus stop is?`
- `Is there a pharmacy near here?`

## Asking for help with tasks

| English                     | Vietnamese                            |
| --------------------------- | ------------------------------------- |
| Could you carry this bag?   | Bạn có thể mang chiếc túi này không?  |
| Would you open the door?    | Bạn có thể mở cửa giúp tôi không?     |
| Can you explain this again? | Bạn có thể giải thích lại được không? |

# Review Unit 3

## What we learned

In Unit 3, you learned four important skills for daily life:

1. **Shopping & Money** — Vocabulary for stores, prices, and shopping phrases
2. **Directions & Places** — Asking for and giving directions
3. **Can / Can't** — Talking about abilities
4. **Describing People** — Appearance and personality

## Quick review

### Shopping & Money

| English            | Vietnamese                     |
| ------------------ | ------------------------------ |
| supermarket        | siêu thị                       |
| cheap / expensive  | rẻ / đắt                       |
| discount           | giảm giá                       |
| How much is this?  | Cái này bao nhiêu tiền?        |
| Can I pay by card? | Tôi có thể trả bằng thẻ không? |

### Directions & Places

| English                 | Vietnamese          |
| ----------------------- | ------------------- |
| Turn left / right       | Rẽ trái / phải      |
| Go straight             | Đi thẳng            |
| next to / behind        | bên cạnh / phía sau |
| Excuse me, where is...? | Xin lỗi, ... ở đâu? |

### Can / Can't

| Pattern                | Example          |
| ---------------------- | ---------------- |
| Subject + can + verb   | I can swim.      |
| Subject + can't + verb | She can't drive. |
| Can + subject + verb?  | Can you help me? |

### Describing People

| Category    | Examples                         |
| ----------- | -------------------------------- |
| Hair        | long, short, black, brown, curly |
| Build       | tall, short, thin, slim          |
| Personality | friendly, kind, funny, serious   |

### Cultural awareness

| Phrase                 | Meaning                      |
| ---------------------- | ---------------------------- |
| read between the lines | understand implied meaning   |
| build rapport          | establish good relationships |

### Complex sentence patterns

- **Although + clause**: contrast
- **Unless + clause**: negative condition
- **Given + noun**: considering
- **Not only... but also**: emphasis

### Formal correspondence

| Opening                | Closing           |
| ---------------------- | ----------------- |

# Proposal Writing

## Structuring a business proposal

A clear proposal follows a logical structure: problem → solution → benefits → ROI.

> **Pattern**: `This proposal outlines our [approach] to [goal]`

### Essential proposal vocabulary

| English                    | Vietnamese                   |
| -------------------------- | ---------------------------- |
| outline                    | phác thảo                    |
| ROI (Return on Investment) | Lợi tức đầu tư               |
| yield results              | mang lại kết quả             |
| deliver value              | tạo giá trị                  |
| phased approach            | cách tiếp cận theo giai đoạn |
| measurable outcomes        | kết quả đo lường được        |

## Standard sections

| Section           | Purpose                  |
| ----------------- | ------------------------ |
| Executive Summary | Overview of the proposal |
| Problem Statement | Define the issue         |
| Proposed Solution | Present your approach    |
| Timeline          | Phased implementation    |
| Expected ROI      | Quantify the value       |

## Sample proposal language

> "This proposal outlines our three-phase approach to digital transformation. Our solution will deliver measurable ROI within twelve months. We are confident this partnership will yield significant long-term value."

## Useful phrases

- We propose to implement...
- The expected outcome is...
- Our team will deliver...
- This investment will yield...

# Food & Drinks

## Common Food

| English   | Vietnamese | Category  |
| --------- | ---------- | --------- |
| rice      | cơm        | main food |
| bread     | bánh mì    | breakfast |
| chicken   | thịt gà    | meat      |
| beef      | thịt bò    | meat      |
| fish      | cá         | seafood   |
| egg       | trứng      | protein   |
| vegetable | rau        | vegetable |
| fruit     | trái cây   | fruit     |
| rice      | cơm        | grain     |
| noodle    | mì / phở   | grain     |
| salad     | salad      | vegetable |

## Common Drinks

| English | Vietnamese |
| ------- | ---------- |
| water   | nước       |
| coffee  | cà phê     |
| tea     | trà        |
| milk    | sữa        |
| juice   | nước ép    |
| soda    | nước ngọt  |

## Using "I like / I don't like"

> **Pattern**: `I like [food].` / `I don't like [food].`

### Examples

| English            | Vietnamese          |
| ------------------ | ------------------- |
| I like rice.       | Tôi thích cơm.      |
| I don't like fish. | Tôi không thích cá. |
| She likes coffee.  | Cô ấy thích cà phê. |

## Using "I would like"

To order food politely, use **"I would like"**:

> **Pattern**: `I would like some [food], please.`

### Examples

| English                             | Vietnamese                        |
| ----------------------------------- | --------------------------------- |
| I would like some rice, please.     | Tôi muốn gọi cơm ạ.               |
| I would like a cup of coffee.       | Tôi muốn gọi một ly cà phê.       |
| We would like two bottles of water. | Chúng tôi muốn gọi hai chai nước. |

## At the Restaurant

Useful phrases for ordering:

| English                     | Vietnamese                     |
| --------------------------- | ------------------------------ |
| Can I see the menu, please? | Tôi có thể xem thực đơn không? |
| What do you recommend?      | Bạn giới thiệu món gì?         |
| I would like...             | Tôi muốn gọi...                |
| The bill, please.           | Tính tiền ạ.                   |

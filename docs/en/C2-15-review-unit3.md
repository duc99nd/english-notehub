# Review Unit 3

## Unit 3 Summary

Unit 3 completes your C2 journey, integrating advanced research communication, formal debate, scholarly publishing, and creative-professional writing. You now possess the complete range of C2 competencies.

## Key Concepts Recap

### 1. Research Presentation Vocabulary (C2-11)

Research presentations, particularly doctoral defenses, require balancing confidence with epistemic humility. Methodological vocabulary and hedging strategies maintain scholarly credibility.

| Concept                           | Application                                    |
| --------------------------------- | ---------------------------------------------- |
| Triangulation                     | Using multiple methods to verify findings      |
| Saturation                        | No new themes emerging in qualitative research |
| "Notwithstanding the limitations" | Acknowledge while defending                    |
| Effect size reporting             | Beyond statistical significance                |

### 2. Formal Debate Grammar (C2-12)

Debate deploys specific grammatical structures for rhetorical impact:

**Key structures:**

- **Cleft sentences**: `It is not X but Y that matters.`
- **Passive constructions**: Impersonal attribution of sources
- **Emphatic "do"**: `The data do show...`
- **Inversion**: `Never has a policy...`

### 3. Writing for Publication (C2-13)

Scholarly publishing follows established conventions:

**Reviewer language:**

```
"Would benefit from" = major revision needed
"Methodology is sound" = at least the methods are okay
"Seems premature" = reject and resubmit later
```

### 4. Professional Poetry (C2-14)

Professional poetry serves occasions, not personal expression:

**Structural pattern:**

1. Acknowledge
2. Invoke
3. Celebrate
4. Commit

# Persuasive Grammar

## Building arguments with grammar

Strong arguments rely not just on facts, but on the grammatical structures that frame them. These patterns help you sound more convincing in presentations and proposals.

### Cleft sentences for emphasis

> **Pattern**: `What matters is [X]`, `It's not [X] but [Y]`

| Structure                                     | Example              |
| --------------------------------------------- | -------------------- |
| What matters is the outcome.                  | Emphasize the result |
| It's not the cost but the value that matters. | Reframe the argument |
| What we need is more time to test.            | State a clear need   |

## Not only... but also (inversion)

> **Pattern**: `Not only + auxiliary + subject + verb, but + subject + also + verb`

| English                                                            | Vietnamese                                                 |
| ------------------------------------------------------------------ | ---------------------------------------------------------- |
| Not only does this reduce costs, but it also improves scalability. | Không chỉ giảm chi phí, mà còn cải thiện khả năng mở rộng. |
| Not only have we saved money, but we have also improved quality.   | Không chỉ tiết kiệm tiền, mà còn cải thiện chất lượng.     |

## Double comparatives

> **Pattern**: `The + comparative... the + comparative`

- The more we test, the better our predictions become.
- The earlier we start, the sooner we finish.
- The harder you work, the more you achieve.

## Subjunctive for strong recommendations

> **Pattern**: `It is essential/vital/crucial that + subject + base verb`

- It is essential that we act now.
- It is vital that the team agrees on priorities.
- It is crucial that stakeholders sign off before launch.

# Review Unit 1

## How to use this review

You just finished Unit 1 — four lessons covering greetings, numbers, daily verbs, and family. This review has four parts:

1. **Vocabulary snapshots** — quick tables to refresh your memory.
2. **Key patterns** — the most useful sentence shapes.
3. **Mixed practice** — exercises that pull from all four lessons.
4. **Self-check** — honest scoring so you know what to revisit.

If you can do the practice without looking back at the lessons, you are ready for Unit 2.

> **Phone numbers**: read each digit separately, pause every 3-4 digits, use "oh" for zero.
> "Zero nine one, two three four, five six seven eight" = 091 234 5678

## Lesson 3 — Daily verbs snapshot

| Base form | Example with "I" | Note |
| --- | --- | --- |
| wake up | I wake up at 6. | base verb after I (no s) |
| eat | I eat breakfast. | base verb after I |
| drink | I drink coffee. | base verb after I |
| go | I go to work. | base verb after I |
| come | I come home. | base verb after I |
| work | I work from 9 to 5. | base verb after I |
| sleep | I sleep at 10. | base verb after I |
| read | I read books. | base verb after I |

> **The rule**: with **I / you / we / they**, use the base verb. With **he / she / it**, add "s" — "She wakes up at six." This rule carries through every lesson.

## Lesson 4 — Family snapshot

| English | Vietnamese | Possessive |
| --- | --- | --- |
| mother / mom | mẹ | **her** name |
| father / dad | bố | **his** name |
| sister | chị / em gái | **her** name |
| brother | anh / em trai | **his** name |
| grandmother | bà | **her** age |
| grandfather | ông | **his** age |

> **Possessives**: "my mother's name is Lan" (one mother → 's) vs "my parents' house" (two parents → s').
> **Pronouns**: I → my, he → his, she → her, they → their.

## Key patterns across all four lessons

> **Pattern A — Introduce yourself**: `Hello, my name is [name]. I'm from [place].`
>
> **Pattern B — Count and say a number**: `My phone number is [digits], [digits].`
>
> **Pattern C — Describe a habit**: `I [verb] [time phrase].`
>
> **Pattern D — Introduce family**: `This is my [member]. [His/Her] name is [name].`

# Should and Must

## Modal verbs

We use **should** and **must** as modal verbs. They come before the main verb.

## Should

Use **should** to give advice or recommendations.

> **Pattern**: `Subject + should + verb`

| English                         | Vietnamese                |
| ------------------------------- | ------------------------- |
| You should eat more vegetables. | Bạn nên ăn nhiều rau hơn. |
| She should study harder.        | Cô ấy nên học chăm hơn.   |
| They should see a doctor.       | Họ nên đi khám bác sĩ.    |

## Must

Use **must** for strong obligation or rules.

> **Pattern**: `Subject + must + verb`

| English                            | Vietnamese                       |
| ---------------------------------- | -------------------------------- |
| You must wear a seatbelt.          | Bạn phải thắt dây an toàn.       |
| Students must submit work on time. | Học sinh phải nộp bài đúng hạn.  |
| You must be 18 to vote.            | Bạn phải đủ 18 tuổi để bỏ phiếu. |

## Should vs Must

| Should               | Must                            |
| -------------------- | ------------------------------- |
| Advice (softer)      | Strong obligation (harder)      |
| You should rest.     | You must rest now.              |
| You should try this. | You must try this - it's great! |

## Negative forms

| Form      | Example                  | Meaning         |
| --------- | ------------------------ | --------------- |
| shouldn't | You shouldn't smoke.     | Không nên       |
| mustn't   | You mustn't tell anyone. | Không được phép |

## Learning outcome

By the end of this lesson, you can write and revise a response about should and must for a named audience, with a clear purpose, relevant support, and next step.

## Scenario practice

### Situation

Write a safety note for a shared workspace with one rule, two recommendations, and a clear reason.

> **Training note:** This situation and its details are fictional. They are designed for language practice, not presented as a real event, policy, study, or legal interpretation.

### Controlled practice

Build a four-part outline: audience, purpose, one concrete supporting detail, and requested next step. Check that every planned sentence serves one of those four parts.

### Guided task

Write 28–90 words for the stated audience. Make the purpose visible in the opening, support it with a concrete detail, and close with a proportionate next step.

### Model response

> **Draft:** You should study harder for the exam. You must finish your homework before going out. You should drink more water every day.
>
> **Revision note:** I connect the main point to one concrete detail. I check the time, person, or action so the listener knows what happens next. Other well-supported responses are possible.

### Why the model works

The model shows one defensible route through the task; it is not a script to memorize. Compare its task completion, language accuracy, audience fit, and clarity with your response, then revise once.

### Transfer task

Rewrite the note as advice for studying at home. Keep the target language, but change the details and register needed for the new context.

# Should and Must

## Modal verbs

We use **should** and **must** as modal verbs. They come before the main verb.

## Should

Use **should** to give advice or recommendations.

> **Pattern**: `Subject + should + verb`

| English                         | Vietnamese                |
| ------------------------------- | ------------------------- |
| You should eat more vegetables. | Bạn nên ăn nhiều rau hơn. |
| She should study harder.        | Cô ấy nên học chăm hơn.   |
| They should see a doctor.       | Họ nên đi khám bác sĩ.    |

## Must

Use **must** for strong obligation or rules.

> **Pattern**: `Subject + must + verb`

| English                            | Vietnamese                       |
| ---------------------------------- | -------------------------------- |
| You must wear a seatbelt.          | Bạn phải thắt dây an toàn.       |
| Students must submit work on time. | Học sinh phải nộp bài đúng hạn.  |
| You must be 18 to vote.            | Bạn phải đủ 18 tuổi để bỏ phiếu. |

## Should vs Must

| Should               | Must                            |
| -------------------- | ------------------------------- |
| Advice (softer)      | Strong obligation (harder)      |
| You should rest.     | You must rest now.              |
| You should try this. | You must try this - it's great! |

## Negative forms

| Form      | Example                  | Meaning         |
| --------- | ------------------------ | --------------- |
| shouldn't | You shouldn't smoke.     | Không nên       |
| mustn't   | You mustn't tell anyone. | Không được phép |

## Practice lab

### Notice the language

Read the situation, then listen to the model once for meaning and once for phrasing.

> **Colleague:** How would you handle **should and must** in this situation?
>
> **You:** You should study harder for the exam.

Notice what the response does before you copy its wording: it gives the listener a clear point, enough context, and a usable next step.

> **Pattern**: clear point + concrete detail or reason + appropriate next step

### Your turn

Write 80–120 words for a colleague or classmate. State the purpose early, support it with a concrete detail, and finish with a clear next step.

### Model response

> You should study harder for the exam. You must finish your homework before going out. You should drink more water every day.

The model is one possible response, not a script you must memorize. Compare its purpose, level of detail, and tone with your version, then revise once.
